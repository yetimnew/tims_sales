## 📂 Folder Descriptions

### `lib/` - Main Source Code
All your Dart code goes here. This is the heart of your Flutter app.

### `lib/config/` - Configuration
- `app_config.dart` - API base URLs, app settings, constants

### `lib/models/` - Data Models
- `driver.dart` - Driver data structure
- `trip.dart` - Trip/Performance data structure
- `truck.dart` - Truck data structure

### `lib/services/` - Business Logic
- `api_service.dart` - Base HTTP client (Dio) with token management
- `auth_service.dart` - Login, logout, token management
- `driver_service.dart` - Get driver profile and assigned truck
- `location_service.dart` - GPS location tracking and sending
- `performance_service.dart` - Get driver performance metrics
- `status_service.dart` - Update driver status (work/truck/trip)
- `trip_service.dart` - Get trips, update trip status

### `lib/screens/` - UI Screens
- `auth/login_screen.dart` - Driver login screen
- `dashboard/dashboard_screen.dart` - Main app dashboard with tabs

### `android/` - Android Platform
Auto-generated by Flutter. Contains Android-specific code and configuration.

### `ios/` - iOS Platform
Auto-generated by Flutter. Contains iOS-specific code and configuration.

Create `lib/utils/` folder:
```

├── storage.dart          # Offline storage helpers
├── validators.dart       # Form validation

```

## 📝 File Organization Rules

1. **One file per class** - Keep classes in separate files
2. **Group by feature** - Related files go in same folder
3. **Clear naming** - Use descriptive names (e.g., `login_screen.dart`)
4. **Import organization** - Group imports: Flutter → Packages → Local
