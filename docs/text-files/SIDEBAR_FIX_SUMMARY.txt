PERMISSION LOGIC EXPLAINED
═══════════════════════════════════════════════════════════════════════════════

The sidebar filters items based on permissions:

IF requiredPermissions = [] (empty array)
  → Confuses the filter
  → Item may not show

IF requiredPermissions = undefined
  → Shows to everyone
  → ✅ CORRECT for Help

IF requiredPermissions = ['specific.permission']
  → Only shows if user has that permission
  → Used for admin/restricted features


YOUR HELP ITEM NOW:
  requiredPermissions: undefined
  = Available to all authenticated users
  = No permission checks needed
