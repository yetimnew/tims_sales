⚡ QUICK SETUP - 5 MINUTES
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Create routes/help.php
────────────────────────────────
Create new file: routes/help.php

Copy this code:
```php
<?php
use Illuminate\Support\Facades\Route;
use App\Http\Controllers\HelpController;

Route::prefix('help')->name('help.')->group(function () {
    Route::get('/', [HelpController::class, 'index'])->name('index');
    Route::get('/{category}', [HelpController::class, 'category'])->name('category');
    Route::get('/{category}/{slug}', [HelpController::class, 'detail'])->name('detail');
});
```


STEP 2: Create app/Http/Controllers/HelpController.php
───────────────────────────────────────────────────────
Create new file: app/Http/Controllers/HelpController.php

Copy this code:
```php
<?php
namespace App\Http\Controllers;
use Inertia\Inertia;

class HelpController extends Controller
{
    public function index()
    {
        return Inertia::render('Help/HelpIndex');
    }

    public function category($category)
    {
        return Inertia::render('Help/HelpCategory', [
            'category' => $category,
            'articles' => [],
        ]);
    }

    public function detail($category, $slug)
    {
        return Inertia::render('Help/HelpDetail', [
            'article' => [],
            'relatedArticles' => [],
        ]);
    }
}
```


STEP 3: Include routes in routes/web.php
─────────────────────────────────────────
Open: routes/web.php
Add at bottom: require __DIR__.'/help.php';


STEP 4: Start Your App
──────────────────────
Terminal: php artisan serve

Or use Laragon:
- Start Laragon
- Click WWW
- Click react-starter-kit


STEP 5: Test It!
────────────────
Visit: http://localhost:8000
or: http://react-starter-kit.local

In sidebar, click: "Help & Documentation"

You'll see: Beautiful help dashboard! 🎉
